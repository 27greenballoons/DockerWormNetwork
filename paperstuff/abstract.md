# Abstract 

This paper aims to document the interaction of malware in a containerized Docker Compose enviroment. There will be a comparison between two models of worms, an AI-powered worm utilizing GANs to learn and improve its movements within a network, and a traditional "dumb" worm serving as a control. By using the same simulated network, the performance of the two worms will be compared and an assessment will be made on which one will be better. Furthermore, a dataset to train the GAN worm will be given to show how it will work.
